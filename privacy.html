プライバシー / Privacy

Updated: 2026-11-15

入力値は保存・送信しません

このツールは入力された見積り金額と請求月数を画面内で計算します。データベース、Cookie、ブラウザ保存領域、アクセス解析、外部APIは使用しません。入力値は画面を閉じるか再読み込みすると消えます。取引先名・個人情報は入力しないでください。

拡張機能は閲覧ページ、履歴、アカウント情報を読みません。特別なブラウザ権限は要求しません。

外部リンク

料金ページや公式資料をクリックすると外部サイトへ移動します。移動先の通常のアクセス記録やプライバシーポリシーは、そのサイトが管理します。比較した金額はリンクに付けません。ウェブ版の配信元は通常のウェブリクエスト情報を取得する場合があります。

English

This tool calculates quote amounts and billed months entirely in the page. It has no database, cookies, persistent browser storage, analytics or external API calls. Inputs disappear on reload or closing. The extension does not read web pages, browsing history or account information, and requests no special browser permissions.

Opening an external link visits a separate website under its own privacy practices. Input figures are never appended to those links. The web host may receive ordinary request metadata needed to serve the web version.
